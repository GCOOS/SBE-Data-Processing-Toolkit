Run the "experiment_TC_delays.sh" bash script on the "01-CONVERT_WORKDIR" level, gie the cruise folder as parameter.
The script will copy folder structure from a template folder, and the .psa files from the cruise CNV folder.
The script also modifies the input and output paths inside those .psa files, as well as the Conductivity delay values inside the AlignCTD.psa file.
